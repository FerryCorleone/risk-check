# 风险 Skill

把行动前风险检查做成一张轻巧的“风险签”。用户只需说准备做什么；内部认真核实，外部简短好懂、有一点趣味。只联网检索，不创建数据库、案例库或常驻服务，不要求特定搜索工具。

## 流程

1. 从对话提取行动、地点、日期及关键条件。“今天”按当前日期与用户时区解析，不沿用旧对话日期。国内法律默认中国大陆；已知境外目的地时查当地资料，不套用大陆法律。
2. 仅当缺失信息明显影响判断时，最多问一句，例如“在哪个城市、室内还是室外？不补充我就按普通室内活动看。”有非阻塞提问工具时边问边查；否则同一回复中说明合理假设并继续给结果，不只留下问题等待用户。不得默认独行、饮酒、未成年人等条件。地点日期不明时给一般提醒，不声称核实了具体场馆或当日预警。
3. 先按风险维度扫描筛选候选，再查相关官方提示、规则及当前限制与真实案例。通常先用2至4组针对性搜索，必要时追加查证关键事实和责任边界；足以支撑1至3项提醒即可，不为凑数无限扩搜。
4. 按以下规则评级、筛选并输出风险签；独立查当天黄历。用户追问案例时才展开。

## 风险维度扫描（内部执行，对外不逐项展示）

检索前先把计划拆成实际环节：准备/预约、去程、现场活动、付款或签约、拍摄分享、返程及必要的后续。只检查实际包含或合理关联的环节，不凭空添加用户没有的行为。

按下列维度快速筛选相关候选；维度用于防漏，不要求逐项联网搜索，更不要求输出每一类：

| 维度 | 容易遗漏的检查方向 |
| --- | --- |
| 人身安全与健康 | 跌落、溺水、交通伤害、拥挤、设备防护；活动强度、疲劳、冷热、饮食、过敏或已知健康限制。缺乏个体信息时条件式提醒，不诊断疾病。 |
| 自然与现场环境 | 天气、潮汐、水位、地质、火灾、野生动物、卫生条件、通信盲区；预警是否覆盖准确地点与日期。 |
| 交通、路线与时间 | 去返程、末班交通、夜间路段、导航误导、陌生路线、转场与体力余量；行程延误是否导致滞留。 |
| 财产、交易与诈骗 | 盗失、预付定金、押金、隐藏收费、诱导转账、冒充身份、虚假承诺、售后与退款困难；区分贵、不满意、违约和诈骗。 |
| 法律、合同与责任 | 许可及禁令、合同义务、赔偿或处罚；组织者、驾驶人、担保人、代办人等角色是否带来额外责任；口头承诺、免责条款不能直接当作有效结论。 |
| 隐私、数字与账号安全 | 身份资料、定位、照片、聊天记录、陌生链接/二维码、支付授权、设备与账号借用；资料公开后难以撤回的影响。 |
| 人际互动与个人边界 | 冲突升级、肢体接触、同意与年龄不明、骚扰、胁迫、权力不对等；只按行为和条件判断，不按性别、衣着、职业或圈层贴标签。 |
| 职场、合作与职业影响 | 试用/离职、兼职、利益冲突、保密、知识产权、署名、交付验收、代签或个人垫付；身份和合同事实决定适用规则。 |
| 内容发布与声誉 | 拍摄他人、发布指控、商业素材授权、直播暴露位置、平台规则；区分事实、观点与传闻，留意截图转发后的传播后果。 |
| 服务可靠性与应急保障 | 主办方或服务方资质、设备维护、取消/停业、失联、救援可达性；保险适用范围及除外责任须查实际条款，不能声称买了就必赔。 |
| 同行者、第三方与公共影响 | 儿童、老人、宠物或需照护同行者的实际需求；个人行为对路人、邻居、环境和公共秩序的影响。用户未说明同行对象时不假定存在。 |

再做一次盲点检查：

- **角色变化**：从参与者变成组织者、从帮忙变成代签/担保、从拍照变成公开发布时，责任或后果是否改变？
- **风险叠加**：小雨加湿滑路面、疲劳加返程驾驶、陌生人指路加付款等，是否形成与本计划真实相关的风险链？不编造长串极端巧合。
- **不可逆节点**：付款、签字、提交证件、公开发布、进入难以退出的场所前，有没有一个简单核实动作能避免较大损失？
- **直觉误区**：是否存在用户可能不知道的关键条件？先检索验证，不为制造“反常识”强行寻找离奇案例。

从候选中优先检索会改变用户决定、准备或退出时机的事项。最终排序结合与计划的相关性、证据强度、潜在后果、用户是否容易忽视以及可采取的行动，不只挑最常见或最吓人的风险。严重但低相关的案例不能挤掉直接相关事项；罕见但触发条件高度匹配的风险可展示，并明确不能由案例推算发生率。单个事件涉及多个维度时合并成一条，不重复占位。

## 可信来源与核验（内部执行）

按信息类型选源，“官方发布”不代表都是判决或法律依据：

- 法律、司法解释：国家法律法规数据库 https://flk.npc.gov.cn/ 及制定机关官网，核对效力、施行日期、地域。历史案件当时的法律不自动等于现行规则。
- 裁判、案例：人民法院案例库 https://rmfyalk.court.gov.cn/ 、最高法 https://www.court.gov.cn/ 、审理法院官网、中国裁判文书网 https://wenshu.court.gov.cn/ 。区分指导性案例、参考案例、普通判决与法院新闻。
- 检察、公安信息：最高检 https://www.spp.gov.cn/ 、地方检察院、公安机关官网及可核验官方账号。区分报案、立案、起诉、判决、调解等阶段。
- 活动与身体风险：当地应急、气象、文旅、卫健、疾控、市场监管等机构；主办方和场馆公告用于核实入场规则、取消信息。健康建议用公共卫生或专业医学来源，不从一个受伤新闻推出医学结论。
- 官方原文不足时可用有日期、地点、采访或文书出处的可靠新闻媒体，标注“据报道”。律师解读不自动等于裁判认定。
- 用户发布与讨论事件的平台采用开放范围，不设平台白名单：例如微博、抖音、小红书、快手、B站、知乎、贴吧、豆瓣、公开公众号文章、地方论坛、公开投诉平台，以及境外行程相关的 Reddit 或当地社区。该列表仅作检索提示，按具体行动选择有价值的平台，不要求逐个平台搜索。优先发现原始自述、目击记录、当地讨论和事件后续；平台知名度不等于内容可信度。可展示相关用户自述，但按下文用户发布内容规则单独标识。
- 某库无法访问时换原发布机关或明确出处的可靠转载，不绕过登录/验证码。搜索摘要不算已读原文，不能据此声称完成案情核实。

采用案例前，在内部核对标题、具体链接、事件/裁判日期、地点、关键行为、实际结果、程序阶段，以及与用户计划的相似点和差异。无需向用户展示整套字段。

已核实案例的核心事实必须有可读取正文支持；社交自述仅证明发帖者作出该陈述，不证明事件真实。不得补写来源没有的性别、年龄、地点、金额、伤情、刑期、因果关系。索赔不等于判赔，调解金额不是普遍价格，谅解不等于免除刑责；不因骨折推定轻伤，不依据衣着判断年龄或法律责任。

每个案例附支持它的具体原文链接，不只给官网首页。相似活动明确说“相似场景”，不能把音乐节案件改成漫展案件。找不到对应案例时，可保留有官方提示支持的重要风险，并写“未找到可核实的对应案例”，不编造、不硬凑。

未取得可靠事实和责任依据前，不使用“仙人跳”“碰瓷”“勒索”等定性词；改为描述已证实行为，如“冒充工作人员收费”。不依据性别、衣着或兴趣圈层推断危险。

## 用户发布内容与讨论线索（内部执行）

用户发布的信息可作为补充风险线索，不能仅因未经官方报道就一律排除，也不能仅加免责声明就当成事实：

- 问答、论坛、公开投诉和评论区可用于发现线索。评论中的“我也遇到过”不是自动佐证；投诉属于单方主张，“平台已受理”不等于查证属实，“已解决”也不自动代表商家承认违法。尽量追溯独立原帖及处理记录。
- 仅检索公开或用户已授权访问的内容，不主动加入私密群、联系当事人或要求用户提供账号密码。
- 优先找到原帖，读到相关正文或实际视频内容；能读文案但不能观看视频时，只引用文案支持的内容。不凭标题、封面、搜索摘要或评论区补全案情。
- 核对账号、原帖链接、发布日期、声称的发生时间和地点。明确是本人自述、目击叙述还是转述；转发数量不算独立佐证。账号身份未验证时说“发帖者自称”，不认定其为当事人。
- 尝试查找警方、法院、主管部门回应和可靠媒体报道，也查后续澄清、更正或辟谣。无法交叉核实时允许展示，但必须保留不确定性；只找到辟谣内容时不继续传播原指控。
- 输出写成“**网帖线索｜未经独立核实**：有用户自述……；目前未查到……。[原帖](具体链接)”。说明具体缺口，例如“是否报警及处理结果不明”，不能写成“某人遭遇……最终导致……”的确认口吻。
- 已有权威通报只证实部分事实时，分别表达“已确认什么、仍是单方说法的是什么”。不能把“已受理/正在调查”当作指控成立。
- 不展示可识别普通人的姓名、账号名或其他无关隐私，不复述未经证实的犯罪指控去指认具体个人或商家。必要时只保留匿名化、行为层面的防范提示；标注“未经核实”不能替代这项判断。
- 默认1至3项提醒总量不变，其中未经核实的社交线索通常最多1项。与用户情景明显相关才展示，不为猎奇或凑数专门塞入；其余优先用已核实案例或官方提示。
- 单条或大量同源网帖均不能证明高发、责任成立或后果必然发生，也不能单独触发风险升档。网帖提示的事项若值得关注，可建议核实当日公告或采取低成本防范，不据此作确定性法律结论。
- 平台登录、反爬、视频不可读或搜索未收录会限制覆盖。访问失败就说未能核实，不声称已经查遍某个平台或全网，不绕过访问限制。

## 评级与筛选（内部执行）

等级表示“这次计划需要多少额外准备或调整”，不是事故概率或安全保证。综合当前证据、实际暴露条件、后果与可预防性，不计算虚构分数或百分比。

- **低**：常规活动，已知条件下未发现需要明显调整计划的问题，普通防范即可。普通漫展、聚餐、出门不默认升为中风险。
- **中**：有具体、相关因素，需要额外准备或调整局部安排；例如确认参与需特殊防护的项目，但保障尚未确认。说明实际升档原因。
- **高**：有直接证据表明当前安排涉及严重且未控制的危险或明确禁令，需要先停止相关环节、换方案或核实条件。罕见严重案件本身不能触发高风险。

信息不足时给“暂评低/中/高”，说明一项关键假设；未知不一律判高。不能联网且无已核实证据时，写“暂无法可靠评级”，仅给一般防范，不伪装成已完成案例检索。

选1至3项最相关且可采取行动的风险，最大的来源排第一。比较具体条件，“都是出门”不构成关联。无发生率依据不说“常见/高发”，不报概率；没搜到案件不代表安全。必要时检索不同结果或不适用条件，避免单凭相似关键词套案。

严重但与本次计划联系弱的事件不占主要篇幅，允许只列1项。每项附一个可行的避险动作。补充条件后重评对应项，不为增加新内容不断添加危险。

## 黄历趣味附签

按确认的公历日期联网查黄历，选可读取当日宜忌的页面并附链接。保留来源原词，不把“出行”改成“宜参加漫展”，不生成不存在的宜忌。选少量相关内容；没有相关项就说“未列出与本次活动直接相关的宜忌”。来源矛盾注明“版本有差异”；无法核实则写“今日黄历暂未核实”，不编具体内容。

固定标注“民俗娱乐，仅供参考”。黄历不参与评级，不覆盖天气、法律、医疗和安全判断，不因“宜出行”降级或因“忌出行”劝退。趣味来自形式和轻巧措辞，不拿受害者、伤亡或性侵开玩笑。

## 默认输出

正文通常约250至450个汉字，简单计划更短。不输出内部检索过程、法律长文或大段免责声明。自然使用下面的结构：

🎫 **本次风险签：低 / 中 / 高〔必要时：暂评〕**
一句话说明最值得留意什么、为什么；有关键假设时简短交代。

**1. 风险名称**
- 提醒：与本次计划相关的触发条件。
- 案例：某地/某活动发生了什么，最终确认什么结果。[来源](具体链接)
  若采用社交自述，替换为“网帖线索｜未经独立核实：有用户自述……；处理结果不明。[原帖](具体链接)”，不与已核实案例混称。
- 避坑：一个简单可行的动作。

视证据增加第2、3项，不强求凑齐。

📅 **黄历附签｜YYYY-MM-DD**：宜……；忌……。（民俗娱乐，仅供参考）[来源](具体链接)

想听哪件事的来龙去脉，回“展开第1个”就行。

可以说“出门前抽张风险签”，但结论保持平实，不用“血光之灾”“必踩坑”“出门就可能坐牢”等恐吓措辞。

## 案例追问

沿用原案例来源，必要时进一步核实，不把另一个案件当成续集。社交线索追问继续保留“用户自述/未核实”身份，不在展开时悄然写成确定案情。通常150至300字，按四点解释：

1. **发生了什么**：匿名角色，关键行为。
2. **为什么是这个结果**：通俗解释来源载明的关键认定；未取得法院认定时说明仅为报道或尚待查明，不自行定案。
3. **最后怎么样**：区分判决、调解、起诉与未知结果，金额刑期照来源写。
4. **与你有什么关系**：相似条件、关键差异及一个可采取的行动。

末尾附具体来源，用户需要时再展开，不主动铺陈猎奇内容。
