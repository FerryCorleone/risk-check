# 风险 Skill（risk-check）

出门、赴约、旅行、参加活动之前，告诉 AI 你打算做什么，它会帮你抽一张有依据的「风险签」。

它会联网查看与你的计划相关的提醒、规则和真实案例，最后只挑 **1～3 件最值得注意的事**，告诉你可以怎么避坑。内容尽量简短、好懂，也不会用吓人的故事代替判断。

## 它能做什么

- **按你的计划来查**：结合地点、日期和活动内容；信息不全时说明假设，必要时只追问一个关键问题。
- **给出可行动的提醒**：用低、中、高表示需要多少额外准备，配上来源和简单做法。
- **认真区分证据**：优先核对官方信息与案例原文；网帖只能作为线索，未经证实会明确标注。
- **加一点趣味**：附上一条当天黄历，但只作民俗娱乐，不参与安全判断。

例如，你可以说：「周六准备去杭州徒步，傍晚下山，帮我抽张风险签。」它会针对当次行程查证；示例并不代表已核实周六的天气或路线。

## 安装

在终端运行：

```bash
npx skills add FerryCorleone/risk-check -g --skill risk-check --agent '*' --yes
```

安装后，在支持 Skill 的 AI 助手里直接说你的计划，例如：「明天去海边露营，有什么需要注意的？」也可以明确说「用 risk-check 检查我的行程」。

Skill 源文件在 [`risk-check/SKILL.md`](risk-check/SKILL.md)。它只定义 AI 的检索与回答方式，不需要自建数据库或常驻服务；实际联网能力取决于你使用的 AI 助手。

## 使用边界

风险等级是出行或行动前的准备提示，不是事故发生概率，也不是安全保证。天气、场馆规则和法律等会变化，请以当时查到的原始来源为准；重要决定仍需结合实际情况判断。
